# OpenAI Realtime API — Voice Interfaces
## Practice

### Lesson Duration
15 minutes

---

## Independent Challenge

Students will:

- Build a realtime voice assistant prototype.
- Test it with multiple interactions.
- Evaluate responsiveness and UX.

---

## Requirements

Each submission must include:

- Description of the interaction flow.
- Observed latency behavior.
- Error handling approach.
- UX improvement ideas.

---

## Stretch Goals (Optional)

- Add wake-word detection.
- Support conversation memory.
- Add fallback to text mode.

---

## Reflection Questions

Students should be able to answer:

- What latency felt unacceptable?
- Where did interruptions break flow?
- How would this scale to many users?
- What safeguards are needed?

---

## Practice Takeaways

- Realtime voice feels alive.
- UX defines success.
- Architecture enables trust.
