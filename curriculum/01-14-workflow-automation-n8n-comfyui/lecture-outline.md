# Workflow Automation — n8n & ComfyUI
## Imitate (Guided Do-Along)


---

## Goal

Students will build an **automated AI workflow** using n8n and ComfyUI.

---

## Project Overview

The workflow will:

- Trigger on an event or schedule.
- Send data to an AI pipeline.
- Receive and store output.
- Complete without manual steps.

---

## Step 1: Workflow Design

Students will define:

- Trigger type.
- Data flow.
- Expected outputs.

Instructor emphasis:
Design before building.

---

## Step 2: n8n Implementation

Students will:
- Create the trigger.
- Add transformation steps.
- Call external APIs.

---

## Step 3: ComfyUI Integration

Students will:
- Configure a ComfyUI pipeline.
- Accept dynamic inputs.
- Return results.

---

## Step 4: Testing and Iteration

Students will:
- Run the workflow.
- Identify failures.
- Refine logic.

---

## Imitation Takeaways

- Automation requires clarity.
- Small workflows scale.
- Errors propagate quickly.
