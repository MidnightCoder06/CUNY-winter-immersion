# Workflow Automation — n8n & ComfyUI
## Demonstrate

### Lesson Duration
15 minutes

---

## Demo Objective

The instructor will demonstrate how to:

- Build a simple n8n workflow.
- Trigger AI generation automatically.
- Use ComfyUI as part of an automation chain.
- Observe end-to-end execution.

---

## Demo Setup

Requirements:

- n8n instance running.
- ComfyUI instance available.
- API keys for required services.

---

## Instructor Walkthrough

### Step 1: n8n Workflow Basics

The instructor will:
- Create a trigger.
- Add processing steps.
- Connect API nodes.

Focus:
Flow over complexity.

---

### Step 2: Integrating ComfyUI

The instructor will:
- Trigger a ComfyUI workflow.
- Pass input parameters.
- Receive generated output.

Discussion:
Why node-based AI pipelines scale.

---

### Step 3: End-to-End Execution

The instructor will:
- Trigger the workflow.
- Observe each step.
- Validate final output.

---

## Demo Observations

- Automation removes friction.
- Errors surface early.
- Visibility matters.

---

## Demo Takeaways

- Automation is orchestration.
- AI workflows benefit from structure.
- Observability matters even here.
