# OpenAI Audio API
## Practice

### Lesson Duration
15 minutes

---

## Independent Challenge

Students will:

- Build a simple audio-based interaction.
- Test it with multiple inputs.
- Evaluate usability and accuracy.

---

## Requirements

Each submission must include:

- Input method description.
- Audio or transcription outputs.
- Observed errors.
- Improvement suggestions.

---

## Stretch Goals (Optional)

- Add streaming audio.
- Support multiple voices.
- Add fallback to text.

---

## Reflection Questions

Students should be able to answer:

- When is audio better than text?
- What failures felt worst?
- How would this work in noisy environments?
- How should errors be communicated?

---

## Practice Takeaways

- Audio humanizes AI.
- UX failures are magnified.
- Careful design builds trust.
