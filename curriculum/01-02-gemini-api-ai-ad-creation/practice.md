# Gemini API — AI Ad Creation  
## Practice

### Lesson Duration
15 minutes

---

## Independent Challenge

Students will extend their ad generator to:

- Generate ads for three different products.
- Support at least two tones.
- Output results in a readable format.

---

## Requirements

The solution must:

- Use the Gemini API.
- Accept dynamic inputs.
- Generate multiple ad variations.

---

## Stretch Goals (Optional)

- Export outputs to a CSV file.
- Add basic input validation.
- Handle API errors gracefully.

---

## Reflection Questions

Students should be able to answer:

- What made some prompts better than others?
- Where could this system break in production?
- How could this be automated end-to-end?
- What business problem does this actually solve?

---

## Practice Takeaways

- AI outputs are only as good as inputs.
- Structure creates leverage.
- This pattern applies to every AI tool going forward.
