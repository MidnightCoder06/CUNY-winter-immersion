## Concepts & Theory

# Gemini API — AI Ad Creation  
## Explain


---

## Goal

Students will build a **basic AI Ad Generator** using the Gemini API.

---

## Project Overview

The script will:

- Accept a product description.
- Accept a target audience.
- Accept a tone.
- Generate:
  - 3 headlines
  - 2 body copy variations
  - 1 call-to-action

---

## Step 1: Project Setup

Students will:

- Initialize a Node.js project.
- Install required dependencies.
- Create a main script file.

---

## Step 2: Input Design

Students will define variables for:

- Product name and description.
- Target customer.
- Desired tone.

Discussion focus:
- Why structured inputs matter.
- How this mirrors real production systems.

---

## Step 3: Prompt Construction

Students will:

- Write a clear system prompt.
- Define formatting rules for output.
- Request multiple variations in one call.

Emphasis:
- Instructions over creativity.
- Repeatability over novelty.

---

## Step 4: API Call

Students will:

- Send the constructed prompt to Gemini.
- Parse the response.
- Log clean, readable outputs.

Instructor checkpoints:
- Prompt clarity.
- Response parsing.
- Error handling basics.

---

## Step 5: Iteration

Students will:

- Modify tone.
- Change the target audience.
- Observe output differences.

---

## Imitation Takeaways

- Most value is in prompt design.
- Code is the easy part.
- Systems beat one-off results.

## Practice Exercise

# Gemini API — AI Ad Creation  
## Practice


---

## Independent Challenge

Students will extend their ad generator to:

- Generate ads for three different products.
- Support at least two tones.
- Output results in a readable format.

---

## Requirements

The solution must:

- Use the Gemini API.
- Accept dynamic inputs.
- Generate multiple ad variations.

---

## Stretch Goals (Optional)

- Export outputs to a CSV file.
- Add basic input validation.
- Handle API errors gracefully.

---

## Reflection Questions

Students should be able to answer:

- What made some prompts better than others?
- Where could this system break in production?
- How could this be automated end-to-end?
- What business problem does this actually solve?

---

## Practice Takeaways

- AI outputs are only as good as inputs.
- Structure creates leverage.
- This pattern applies to every AI tool going forward.
