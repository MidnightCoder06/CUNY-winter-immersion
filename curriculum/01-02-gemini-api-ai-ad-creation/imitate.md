# Gemini API — AI Ad Creation  
## Imitate (Guided Code-Along)

### Lesson Duration
45 minutes

---

## Goal

Students will build a **basic AI Ad Generator** using the Gemini API.

---

## Project Overview

The script will:

- Accept a product description.
- Accept a target audience.
- Accept a tone.
- Generate:
  - 3 headlines
  - 2 body copy variations
  - 1 call-to-action

---

## Step 1: Project Setup

Students will:

- Initialize a Node.js project.
- Install required dependencies.
- Create a main script file.

---

## Step 2: Input Design

Students will define variables for:

- Product name and description.
- Target customer.
- Desired tone.

Discussion focus:
- Why structured inputs matter.
- How this mirrors real production systems.

---

## Step 3: Prompt Construction

Students will:

- Write a clear system prompt.
- Define formatting rules for output.
- Request multiple variations in one call.

Emphasis:
- Instructions over creativity.
- Repeatability over novelty.

---

## Step 4: API Call

Students will:

- Send the constructed prompt to Gemini.
- Parse the response.
- Log clean, readable outputs.

Instructor checkpoints:
- Prompt clarity.
- Response parsing.
- Error handling basics.

---

## Step 5: Iteration

Students will:

- Modify tone.
- Change the target audience.
- Observe output differences.

---

## Imitation Takeaways

- Most value is in prompt design.
- Code is the easy part.
- Systems beat one-off results.
