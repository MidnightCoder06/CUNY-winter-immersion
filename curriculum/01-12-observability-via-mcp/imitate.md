# Observability via MCP
## Imitate (Guided Do-Along)

### Lesson Duration
45 minutes

---

## Goal

Students will use MCP to perform **AI-assisted observability analysis**.

---

## Exercise Overview

Students will:

- Connect to a CloudWatch MCP server.
- Query logs and metrics.
- Use AI to assist diagnosis.
- Validate conclusions manually.

---

## Step 1: MCP Connection

Students will:
- Review MCP server configuration.
- Understand available tools.
- Test connectivity.

Instructor emphasis:
Permissions define capability.

---

## Step 2: Log Investigation

Students will:
- Query recent error logs.
- Filter by service or function.
- Extract key patterns.

---

## Step 3: Metric Inspection

Students will:
- Query latency or error-rate metrics.
- Identify spikes.
- Compare against baseline.

---

## Step 4: AI-Assisted Reasoning

Students will:
- Ask the model to summarize findings.
- Propose likely root causes.
- Cross-check with raw data.

---

## Imitation Takeaways

- AI augments investigation.
- Raw data still matters.
- MCP enables repeatable analysis.
