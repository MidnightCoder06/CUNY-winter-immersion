# Observability via MCP
## Demonstrate

### Lesson Duration
15 minutes

---

## Demo Objective

The instructor will demonstrate how to:

- Configure an MCP server.
- Connect an AI agent to the CloudWatch MCP server.
- Query logs and metrics through MCP.
- Interpret AI-assisted observability outputs.

---

## Demo Setup

Requirements:

- AWS account with CloudWatch data.
- CloudWatch MCP server configured.
- MCP-compatible AI client.

---

## Instructor Walkthrough

### Step 1: MCP Server Overview

The instructor will:
- Explain the MCP server configuration.
- Review exposed tools and capabilities.

Key point:
MCP defines *what the model is allowed to do*.

---

### Step 2: Querying Logs via MCP

The instructor will:
- Issue a log query through MCP.
- Filter by time range and severity.
- Review structured results.

---

### Step 3: Querying Metrics via MCP

The instructor will:
- Request recent metrics.
- Compare values across time windows.
- Identify anomalies.

---

### Step 4: AI Interpretation

The instructor will:
- Ask the model to explain observed behavior.
- Validate reasoning against raw data.

---

## Demo Observations

- MCP outputs are structured.
- AI reasoning improves with real data.
- Guardrails matter.

---

## Demo Takeaways

- MCP bridges reasoning and reality.
- Observability becomes interactive.
- AI assists, humans verify.
