# Observability via MCP
## Explain


---

## Demo Objective

The instructor will demonstrate how to:

- Configure an MCP server.
- Connect an AI agent to the CloudWatch MCP server.
- Query logs and metrics through MCP.
- Interpret AI-assisted observability outputs.

---

## Demo Setup

Requirements:

- AWS account with CloudWatch data.
- CloudWatch MCP server configured.
- MCP-compatible AI client.

---

## Instructor Walkthrough

### Step 1: MCP Server Overview

The instructor will:
- Explain the MCP server configuration.
- Review exposed tools and capabilities.

Key point:
MCP defines *what the model is allowed to do*.

---

### Step 2: Querying Logs via MCP

The instructor will:
- Issue a log query through MCP.
- Filter by time range and severity.
- Review structured results.

---

### Step 3: Querying Metrics via MCP

The instructor will:
- Request recent metrics.
- Compare values across time windows.
- Identify anomalies.

---

### Step 4: AI Interpretation

The instructor will:
- Ask the model to explain observed behavior.
- Validate reasoning against raw data.

---

## Demo Observations

- MCP outputs are structured.
- AI reasoning improves with real data.
- Guardrails matter.

---

## Demo Takeaways

- MCP bridges reasoning and reality.
- Observability becomes interactive.
- AI assists, humans verify.

---

# Observability via MCP
## Imitate (Guided Do-Along)


---

## Goal

Students will use MCP to perform **AI-assisted observability analysis**.

---

## Exercise Overview

Students will:

- Connect to a CloudWatch MCP server.
- Query logs and metrics.
- Use AI to assist diagnosis.
- Validate conclusions manually.

---

## Step 1: MCP Connection

Students will:
- Review MCP server configuration.
- Understand available tools.
- Test connectivity.

Instructor emphasis:
Permissions define capability.

---

## Step 2: Log Investigation

Students will:
- Query recent error logs.
- Filter by service or function.
- Extract key patterns.

---

## Step 3: Metric Inspection

Students will:
- Query latency or error-rate metrics.
- Identify spikes.
- Compare against baseline.

---

## Step 4: AI-Assisted Reasoning

Students will:
- Ask the model to summarize findings.
- Propose likely root causes.
- Cross-check with raw data.

---

## Imitation Takeaways

- AI augments investigation.
- Raw data still matters.
- MCP enables repeatable analysis.
