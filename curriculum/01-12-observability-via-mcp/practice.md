# Observability via MCP
## Practice

### Lesson Duration
15 minutes

---

## Independent Challenge

Students will:

- Investigate a simulated production issue.
- Use MCP queries to gather evidence.
- Produce a concise incident summary.

---

## Requirements

Each submission must include:

- Logs queried via MCP.
- Metrics reviewed.
- AI-generated hypothesis.
- Human-verified conclusion.

---

## Stretch Goals (Optional)

- Create a reusable MCP query workflow.
- Propose new MCP tools.
- Design an AI on-call assistant flow.

---

## Reflection Questions

Students should be able to answer:

- What did MCP make easier?
- Where could AI mislead?
- How do permissions affect safety?
- How would this scale across teams?

---

## Practice Takeaways

- MCP operationalizes AI reasoning.
- Observability becomes interactive.
- Human judgment remains final.
