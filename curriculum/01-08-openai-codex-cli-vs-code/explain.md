# OpenAI Codex — CLI & VS Code Integration
## Explain

### Lesson Duration
10–15 minutes

---

## Terminal Objectives (SWBAT)

By the end of this section, students will be able to:

- Explain what OpenAI Codex is and how it differs from general LLM usage.
- Describe how Codex assists developers in real workflows.
- Identify appropriate use cases for Codex in CLI and IDE environments.
- Explain the risks of over-reliance on AI coding tools.

---

## What Is OpenAI Codex?

OpenAI Codex is a code-focused AI model optimized for understanding and generating source code.  
It is designed to assist developers directly in their tools.

Think of Codex as **an always-on junior engineer**.  
Fast. Tireless. Occasionally wrong.

---

## What Does Codex Do Well?

Codex excels at:

- Code generation.
- Refactoring.
- Explaining unfamiliar code.
- Writing tests.
- Translating between languages.

It does not replace understanding.  
It accelerates implementation.

---

## Why Use Codex in the CLI or IDE?

Codex is powerful because it operates **where developers already work**.

Benefits include:
- Reduced context switching.
- Faster iteration.
- Immediate feedback.
- Lower cognitive load.

The value is not novelty.  
The value is **flow**.

---

## Risks and Limitations

Common risks include:

- Blind trust in generated code.
- Subtle logic errors.
- Security vulnerabilities.
- Poor architectural decisions.

Codex speeds execution.  
Judgment remains human.

---

## Mental Model

Codex is not a senior engineer.  
It is a **force multiplier** for disciplined developers.

---

## Key Takeaways

- Codex assists, it does not decide.
- Human review is mandatory.
- Productivity gains come from integration, not automation alone.
