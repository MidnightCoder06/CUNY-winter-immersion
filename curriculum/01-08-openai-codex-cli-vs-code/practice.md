# OpenAI Codex — CLI & VS Code Integration
## Practice

### Lesson Duration
15 minutes

---

## Independent Challenge

Students will:

- Use Codex to assist with a small coding task.
- Review and modify the generated code.
- Write a short explanation of changes made.

---

## Requirements

Each submission must include:

- The original Codex prompt.
- The generated code.
- The final revised code.
- A brief rationale for changes.

---

## Stretch Goals (Optional)

- Add unit tests.
- Identify a potential security issue.
- Compare Codex output to a manual solution.

---

## Reflection Questions

Students should be able to answer:

- Where did Codex help most?
- Where did it mislead?
- How did human judgment improve the result?
- When should Codex not be used?

---

## Practice Takeaways

- AI coding tools amplify habits.
- Good habits scale up.
- Bad habits scale faster.
