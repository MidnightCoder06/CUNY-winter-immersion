# OpenAI Codex — CLI & VS Code Integration
## Imitate (Guided Do-Along)

### Lesson Duration
45 minutes

---

## Goal

Students will integrate Codex into their development workflow and use it responsibly.

---

## Project Overview

Students will:

- Use Codex to generate code.
- Refactor existing functions.
- Explain unfamiliar code sections.
- Validate outputs manually.

---

## Step 1: Environment Setup

Students will:
- Install the Codex CLI or VS Code extension.
- Verify connectivity.
- Configure basic settings.

---

## Step 2: Code Generation

Students will:
- Prompt Codex to write a small function.
- Compare AI output to expectations.

Instructor emphasis:
Understand before running.

---

## Step 3: Refactoring

Students will:
- Ask Codex to refactor existing code.
- Evaluate readability and correctness.

Discussion:
Why cleaner code matters.

---

## Step 4: Explanation Mode

Students will:
- Select a code block.
- Ask Codex to explain it.
- Identify gaps or errors in explanation.

---

## Imitation Takeaways

- Codex accelerates routine work.
- Understanding prevents damage.
- Speed without review creates debt.
