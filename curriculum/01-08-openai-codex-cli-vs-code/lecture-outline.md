# OpenAI Codex — CLI & VS Code Integration
## Explain


---

## Demo Objective

The instructor will demonstrate how to:

- Use Codex via the CLI.
- Use Codex inside Visual Studio Code.
- Generate, refactor, and explain code.
- Evaluate AI-generated suggestions critically.

---

## Demo Setup

Requirements:

- Codex access enabled.
- VS Code installed.
- Sample code repository.

---

## Instructor Walkthrough

### Step 1: CLI Usage

The instructor will:
- Run Codex commands from the terminal.
- Generate code snippets.
- Explain command intent vs output.

Focus:
Understanding what Codex was asked to do.

---

### Step 2: VS Code Extension

The instructor will:
- Trigger inline suggestions.
- Ask Codex to explain existing code.
- Refactor a small function.

Students will observe:
- Speed of suggestions.
- Areas requiring correction.

---

## Code Review Discussion

The instructor will:
- Review generated code.
- Identify correct vs risky output.
- Emphasize validation and testing.

---

## Demo Observations

- Codex is fast.
- Codex is confident.
- Codex is not always correct.

---

## Demo Takeaways

- Treat AI output as a draft.
- Review like a human reviewer.
- Trust increases with verification.

# OpenAI Codex — CLI & VS Code Integration
## Imitate (Guided Do-Along)


---

## Goal

Students will integrate Codex into their development workflow and use it responsibly.

---

## Project Overview

Students will:

- Use Codex to generate code.
- Refactor existing functions.
- Explain unfamiliar code sections.
- Validate outputs manually.

---

## Step 1: Environment Setup

Students will:
- Install the Codex CLI or VS Code extension.
- Verify connectivity.
- Configure basic settings.

---

## Step 2: Code Generation

Students will:
- Prompt Codex to write a small function.
- Compare AI output to expectations.

Instructor emphasis:
Understand before running.

---

## Step 3: Refactoring

Students will:
- Ask Codex to refactor existing code.
- Evaluate readability and correctness.

Discussion:
Why cleaner code matters.

---

## Step 4: Explanation Mode

Students will:
- Select a code block.
- Ask Codex to explain it.
- Identify gaps or errors in explanation.

---

## Imitation Takeaways

- Codex accelerates routine work.
- Understanding prevents damage.
- Speed without review creates debt.

# OpenAI Codex — CLI & VS Code Integration
## Practice


---

## Independent Challenge

Students will:

- Use Codex to assist with a small coding task.
- Review and modify the generated code.
- Write a short explanation of changes made.

---

## Requirements

Each submission must include:

- The original Codex prompt.
- The generated code.
- The final revised code.
- A brief rationale for changes.

---

## Stretch Goals (Optional)

- Add unit tests.
- Identify a potential security issue.
- Compare Codex output to a manual solution.

---

## Reflection Questions

Students should be able to answer:

- Where did Codex help most?
- Where did it mislead?
- How did human judgment improve the result?
- When should Codex not be used?

---

## Practice Takeaways

- AI coding tools amplify habits.
- Good habits scale up.
- Bad habits scale faster.
