# OpenAI Codex — CLI & VS Code Integration
## Demonstrate

### Lesson Duration
15 minutes

---

## Demo Objective

The instructor will demonstrate how to:

- Use Codex via the CLI.
- Use Codex inside Visual Studio Code.
- Generate, refactor, and explain code.
- Evaluate AI-generated suggestions critically.

---

## Demo Setup

Requirements:

- Codex access enabled.
- VS Code installed.
- Sample code repository.

---

## Instructor Walkthrough

### Step 1: CLI Usage

The instructor will:
- Run Codex commands from the terminal.
- Generate code snippets.
- Explain command intent vs output.

Focus:
Understanding what Codex was asked to do.

---

### Step 2: VS Code Extension

The instructor will:
- Trigger inline suggestions.
- Ask Codex to explain existing code.
- Refactor a small function.

Students will observe:
- Speed of suggestions.
- Areas requiring correction.

---

## Code Review Discussion

The instructor will:
- Review generated code.
- Identify correct vs risky output.
- Emphasize validation and testing.

---

## Demo Observations

- Codex is fast.
- Codex is confident.
- Codex is not always correct.

---

## Demo Takeaways

- Treat AI output as a draft.
- Review like a human reviewer.
- Trust increases with verification.
