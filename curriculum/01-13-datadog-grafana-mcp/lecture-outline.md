# Datadog & Grafana MCP Servers
## Explain


---

## Demo Objective

The instructor will demonstrate how to:

- Connect AI systems to Datadog and Grafana via MCP.
- Query metrics and logs through MCP servers.
- Compare insights from Datadog and Grafana.
- Validate AI-generated conclusions.

---

## Demo Setup

Requirements:

- Datadog account with telemetry data.
- Grafana instance with configured data sources.
- MCP servers for both platforms.
- MCP-compatible AI client.

---

## Instructor Walkthrough

### Step 1: Datadog MCP Server

The instructor will:
- Review available MCP tools.
- Query service-level metrics.
- Inspect error rates and latency.

Focus:
High-level system health.

---

### Step 2: Grafana MCP Server

The instructor will:
- Query time-series data.
- Inspect detailed visualizations.
- Explore historical trends.

Focus:
Granularity and context.

---

### Step 3: AI Interpretation

The instructor will:
- Ask the AI to summarize system health.
- Compare interpretations across tools.
- Cross-check against raw data.

---

## Demo Observations

- Datadog provides quick correlation.
- Grafana enables deep dives.
- AI benefits from multiple perspectives.

---

## Demo Takeaways

- No single tool tells the whole story.
- MCP enables cross-tool reasoning.
- Human validation remains critical.

## Independent Challenge

Students will:

- Investigate a simulated incident.
- Use both Datadog and Grafana MCP servers.
- Produce a concise incident report.

---

## Requirements

Each submission must include:

- Metrics or logs queried from Datadog.
- Data queried from Grafana.
- AI-generated summary.
- Human-reviewed conclusion.

---

## Stretch Goals (Optional)

- Design a reusable MCP playbook.
- Propose alert improvements.
- Identify blind spots in telemetry.

---

## Reflection Questions

Students should be able to answer:

- When was Datadog more useful?
- When was Grafana more useful?
- How did AI reasoning help or hurt?
- What safeguards are needed?

---

## Practice Takeaways

- Multiple tools improve insight.
- MCP enables AI-assisted operations.
- Humans remain accountable.
